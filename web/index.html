Buscar patrón (Backward Search)

Escribe un patrón. La búsqueda procesa los caracteres de derecha a izquierda, acotando el rango [lo, hi) paso a paso.

Resumen

Suffix Array + BWT

Cada fila es un sufijo ordenado. F = primer carácter, L = último (la BWT). Durante la búsqueda, las filas dentro del rango [lo, hi) se resaltan.

Tabla C

C[c] = número de caracteres en el texto estrictamente menores que c.

Wavelet Tree

Cada nodo descompone el alfabeto en dos mitades. Los bits indican a qué lado fue cada carácter.
